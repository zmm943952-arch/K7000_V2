# 客户旧包Y8诊断

已验证事实：用户确认客户使用 D:\RfpTestStation_BurnOnly_20260803_FixtureInterlock。对应本地发布包 AppSettings.json 默认为 Hardware，计划为 Runtime/TestPlans/Rfp7000BurnOnly.testplan.json。该计划 result.output 的 enablePhysicalResultOutputs=false，productPowerOutputChannel=6；Y6 在此旧包承担产品电源控制，而非当前工作区完整计划中的 PASS 脉冲职责。

修复前执行器在 enablePhysicalResultOutputs=false 时跳过 OK/NG 灯及 PASS 脉冲分支。SaveFixtureFlowSettingsToTestPlan 保存 passPulseOutputChannel/passPulseMs，但不改变 enablePhysicalResultOutputs。仅在界面填写 Y8 并保存，不能启用这个烧录计划的 PASS 脉冲。
